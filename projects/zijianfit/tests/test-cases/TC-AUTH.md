## TC-AUTH-001: 新用户首次使用微信登录

**优先级**: P0  
**类型**: 功能测试 + E2E  
**用户故事**: US1

### 前置条件
- 用户未登录
- 微信已安装
- 网络正常

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 打开 App | 显示登录页面，有"微信登录"按钮 |
| 2 | 点击"微信登录"按钮 | 跳转到微信授权页面 |
| 3 | 点击"允许"授权 | 返回 App，显示加载中 |
| 4 | 等待登录完成 | 显示"获取手机号"引导页 |
| 5 | 点击"授权手机号" | 微信一键获取弹窗 |
| 6 | 点击"允许" | 手机号绑定成功，跳转首页 |
| 7 | 检查首页 | 显示本周训练计划 |

### 验证点
- [ ] 微信 SDK 调用正确
- [ ] `POST /api/auth/wechat` 返回 200
- [ ] Token 保存到 AsyncStorage
- [ ] 用户记录创建（isNewUser = true）
- [ ] `POST /api/auth/phone` 返回 200
- [ ] 手机号解密正确
- [ ] 首页数据加载成功

### 测试数据
```json
{
  "code": "wx_test_code_new_user",
  "encryptedData": "test_encrypted_phone",
  "iv": "test_iv"
}
```

### 预期 API 响应

**登录响应**:
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": "user-uuid",
      "openid": "test_openid_new",
      "phone": null,
      "isNewUser": true
    }
  }
}
```

**绑定手机号响应**:
```json
{
  "success": true,
  "data": {
    "phone": "138****8888"
  }
}
```

### 备注
- 需要 Mock 微信 SDK
- 测试环境需要配置测试 AppID

## TC-AUTH-003: Token 过期自动刷新

**优先级**: P0  
**类型**: 功能测试 + API

### 前置条件
- 用户已登录
- Token 已过期

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 发起 API 请求 | 返回 401 |
| 2 | 自动调用刷新接口 | `POST /api/auth/refresh` |
| 3 | 获取新 Token | 返回新 Token |
| 4 | 重试原请求 | 返回 200 |
| 5 | 检查本地存储 | 新 Token 已保存 |

### 验证点
- [ ] 401 响应正确识别
- [ ] 刷新接口调用
- [ ] 新 Token 获取成功
- [ ] 原请求重试成功
- [ ] 新 Token 已保存

### 测试数据
```json
{
  "expiredToken": "expired_jwt_token",
  "validRefreshToken": "valid_refresh_token"
}
```

### 预期 API 响应
```json
{
  "success": true,
  "data": {
    "token": "new_jwt_token"
  }
}
```
