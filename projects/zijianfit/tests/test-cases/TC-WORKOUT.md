## TC-WORKOUT-001: 查看本周训练计划

**优先级**: P0  
**类型**: 功能测试 + API  
**用户故事**: US2

### 前置条件
- 用户已登录
- 训练计划已生成

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 进入首页 | 自动加载本周计划 |
| 2 | 检查显示 | 显示 7 天卡片 |
| 3 | 检查训练日 | 显示标题（如"胸肌训练"）和动作数 |
| 4 | 检查休息日 | 显示"休息"标签 |
| 5 | 检查日期 | 日期从周一到周日 |

### 验证点
- [ ] `GET /api/plans/current` 返回 200
- [ ] 7 天完整展示
- [ ] 训练日/休息日区分显示
- [ ] 动作数量正确
- [ ] 日期计算正确（周一到周日）

### 测试数据
```json
{
  "userId": "test-user-001",
  "weekNumber": 1,
  "year": 2026
}
```

### 预期 API 响应
```json
{
  "success": true,
  "data": {
    "id": "plan-uuid",
    "weekNumber": 1,
    "year": 2026,
    "days": [
      {
        "dayOfWeek": 1,
        "date": "2026-03-02",
        "isRestDay": false,
        "title": "上肢力量 + 稳态慢跑",
        "label": "8 个动作",
        "exerciseCount": 8
      },
      {
        "dayOfWeek": 2,
        "date": "2026-03-03",
        "isRestDay": true,
        "title": "休息",
        "label": "休息",
        "exerciseCount": 0
      }
    ]
  }
}
```
