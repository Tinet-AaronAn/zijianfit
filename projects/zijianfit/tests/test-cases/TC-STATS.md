## TC-STATS-001: 完成训练自动打卡

**优先级**: P0  
**类型**: 功能测试 + API  
**用户故事**: US4

### 前置条件
- 用户已登录
- 完成训练

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 完成训练 | 自动调用打卡接口 |
| 2 | 检查响应 | 返回成功 |
| 3 | 检查首页 | 当日卡片显示"已完成"标记 |
| 4 | 检查状态 | isCompleted = true |

### 验证点
- [ ] `POST /api/progress/checkin` 调用成功
- [ ] 状态更新成功
- [ ] 首页 UI 更新

### 测试数据
```json
{
  "planId": "test-plan-001",
  "date": "2026-03-02"
}
```

### 预期 API 响应
```json
{
  "success": true,
  "data": {
    "id": "progress-uuid",
    "isCompleted": true,
    "completedAt": "2026-03-02T20:30:00Z"
  }
}
```
