## TC-NOTIF-001: 设置训练提醒时间

**优先级**: P1  
**类型**: E2E  
**用户故事**: US6

### 前置条件
- 用户已登录
- 进入设置页

### 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 找到"训练提醒"设置项 | 显示当前时间（默认 20:00） |
| 2 | 点击修改 | 显示时间选择器 |
| 3 | 选择 19:30 | 时间选择器关闭 |
| 4 | 检查显示 | 显示"19:30" |
| 5 | 退出设置页 | 设置已保存 |

### 验证点
- [ ] 时间选择器正常
- [ ] 设置保存成功
- [ ] 本地存储正确

### 测试数据
```json
{
  "reminderTime": "19:30"
}
```
