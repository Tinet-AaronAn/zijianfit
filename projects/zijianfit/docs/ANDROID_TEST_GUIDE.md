## 📋 您需要做的事情

### ✅ 第1步：准备 Android 手机（1分钟）

1. **开启开发者模式**:
   ```
   设置 → 关于手机 → 版本信息 → 连续点击"版本号" 7次
   ```

2. **开启 USB 调试**:
   ```
   设置 → 开发者选项 → USB 调试（开启）
   ```

3. **连接电脑**:
   - 使用数据线连接手机和电脑
   - 手机上选择"允许 USB 调试"

---

### ✅ 第2步：获取电脑的局域网 IP（1分钟）

#### macOS / Linux
```bash
# 方式1
ifconfig | grep "inet " | grep -v 127.0.0.1

# 方式2
ip addr show | grep "inet " | grep -v 127.0.0.1

# 方式3（推荐）
系统偏好设置 → 网络 → Wi-Fi → 高级 → TCP/IP → IPv4地址
```

**示例**: `192.168.1.100` 或 `192.168.0.105`

#### Windows
```bash
# CMD
ipconfig

# 查找 "无线局域网适配器 WLAN" → IPv4 地址
```
