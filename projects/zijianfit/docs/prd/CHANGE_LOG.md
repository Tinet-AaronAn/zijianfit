## 新需求详解

### 1. 用户注册

#### 接口定义
```
POST /api/auth/register
```

#### 请求参数
```json
{
  "username": "string",      // 必填：4-20字符，字母数字下划线
  "password": "string",      // 必填：6-20字符，至少包含字母和数字
  "confirmPassword": "string", // 必填：与password一致
  "nickname": "string"       // 可选：昵称，最多20字符
}
```

#### 返回结果
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "username": "string",
      "nickname": "string",
      "createdAt": "2026-03-03T00:00:00Z"
    },
    "token": "jwt_token_string"
  }
}
```

#### 错误码
- `USERNAME_EXISTS` - 用户名已存在
- `USERNAME_INVALID` - 用户名格式不正确
- `PASSWORD_INVALID` - 密码格式不正确
- `PASSWORD_MISMATCH` - 两次密码不一致
- `NICKNAME_TOO_LONG` - 昵称过长

---

### 2. 用户登录

#### 接口定义
```
POST /api/auth/login
```

#### 请求参数
```json
{
  "username": "string",  // 必填：用户名
  "password": "string"   // 必填：密码
}
```

#### 返回结果
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "username": "string",
      "nickname": "string",
      "avatar": "string"
    },
    "token": "jwt_token_string",
    "expiresIn": 604800  // 7天（秒）
  }
}
```

#### 错误码
- `USER_NOT_FOUND` - 用户不存在
- `PASSWORD_ERROR` - 密码错误
- `PARAMS_ERROR` - 参数验证失败

---

### 3. 验证规则

#### 用户名
- **长度**: 4-20个字符
- **字符**: 字母、数字、下划线
- **唯一性**: 全局唯一
- **实时验证**: 前端实时检查格式

#### 密码
- **长度**: 6-20个字符
- **复杂度**: 至少包含字母和数字
- **安全性**: 使用 bcrypt 加密（salt rounds: 10）
- **强度提示**: 前端显示密码强度

#### 昵称
- **长度**: 最多20个字符
- **可选**: 非必填
- **默认**: 如果不填，使用用户名

## 风险评估

### 技术风险
- **低风险**: 用户名密码登录是成熟方案
- **已验证**: bcrypt 加密、JWT 认证已实现
- **可回退**: 保留微信登录接口，随时可切换

### 用户体验风险
- **需要记忆**: 用户需要记忆用户名密码
- **缓解措施**: 提供密码强度提示、记住密码功能

### 安全风险
- **暴力破解**: 使用速率限制防护
- **弱密码**: 强制密码复杂度要求
- **数据泄露**: bcrypt 加密 + HTTPS
