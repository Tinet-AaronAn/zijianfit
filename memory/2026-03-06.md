**发现问题**:

#### Bug #1: HomeScreen 渲染崩溃 🔴

**错误信息**:
```
TypeError: weeklyPlans.map is not a function (it is undefined)
TypeError: plans.find is not a function (it is undefined)
```

**根本原因**:
- API 返回格式: `{ success: true, data: { id, days: [...] } }`
- 前端错误使用: `const plans = response.data` （response.data 是对象，不是数组）

**修复方案**:
```typescript
// ❌ 错误代码
const plans = response.data;
setWeeklyPlans(plans);

// ✅ 正确代码
if (response.success && response.data && response.data.days) {
  const plans = response.data.days;
  setWeeklyPlans(plans);
}
```

**修复文件**:
- `mobile/src/screens/HomeScreen.tsx` 第 56-66 行

**验证结果**: ✅ 修复成功

#### Bug #2: 训练详情页加载失败 🔴

**错误信息**:
```
加载训练计划失败: Error: 计划不存在
GET /api/plans/undefined 404
```

**根本原因**:
1. **后端 API 返回数据缺少字段**:
   - API: `/api/plans/current`
   - 返回的 days 数组中没有 `id` 和 `planId` 字段
   
2. **前端导航参数错误**:
   ```typescript
   navigation.navigate('WorkoutDetail', { planId: todayPlan.id })
   // todayPlan.id 是 undefined！
   ```

3. **训练详情页 API 调用错误**:
   - 错误 API: `GET /api/plans/${planId}` (查询整个计划)
   - 正确 API: `GET /api/plans/${planId}/days/${dayOfWeek}` (查询某天训练)

**修复方案**:

1. **后端修复** - `backend/src/controllers/plans.controller.ts`:
   ```typescript
   // 添加 DayPlan ID 和 planId
   return {
     id: dayPlan.id,        // ✅ 添加
     planId: dayPlan.planId, // ✅ 添加
     dayOfWeek: dayPlan.dayOfWeek,
     ...
   };
   ```

2. **前端修复** - `mobile/src/screens/HomeScreen.tsx`:
   ```typescript
   // 传递正确的参数
   navigation.navigate('WorkoutDetail', { 
     planId: todayPlan.planId,    // ✅ Plan ID
     dayOfWeek: todayPlan.dayOfWeek // ✅ 星期几
   })
   ```

3. **前端修复** - `mobile/src/screens/WorkoutDetailScreen.tsx`:
   ```typescript
   // 使用正确的 API
   const response = await api.get(`/plans/${planId}/days/${dayOfWeek}`);
   ```

**修复文件**:
- `backend/src/controllers/plans.controller.ts` (2 处修复)
- `mobile/src/screens/HomeScreen.tsx` (2 处修复)
- `mobile/src/screens/WorkoutDetailScreen.tsx` (1 处修复)
