## 选择标准

✅ **优先选择**：
- 播放量高（>10万）
- 点赞多、评论好
- 有专业教练讲解
- 动作示范清晰
- 时长 30-120 秒

❌ **避免选择**：
- 动作不标准
- 画面模糊
- 广告太多
- 时长过短（<15秒）或过长（>5分钟）

---

## 记录格式

找到视频后，记录：
1. **视频链接**（分享 → 复制链接）
2. **作者名称**
3. **视频时长**

示例：
```
1. 哑铃推举
   链接: https://www.xiaohongshu.com/explore/xxxxx
   作者: 健身教练小王
   时长: 45秒
```

## 快速操作

1. 打开小红书/抖音
2. 复制上方关键词
3. 搜索并选择视频
4. 点击分享 → 复制链接
5. 记录信息
6. 发给我
