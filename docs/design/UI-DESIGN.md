## 1. 设计规范

### 1.1 设计理念

**关键词**: 简洁 · 运动 · 专业 · 高效

参考 Keep 的设计语言，强调：
- 清晰的信息层级
- 醒目的操作引导
- 运动感与力量感
- 低认知负担

### 1.4 间距系统

```
┌─────────────────────────────────────────────────────────────┐
│  Token      值      用途                                      │
├─────────────────────────────────────────────────────────────┤
│  xs         4px     图标与文字间距、紧凑元素间距               │

│  md         16px    标准内边距、卡片内容间距                   │
│  lg         24px    区块间距                                  │
│  xl         32px    页面边距、大区块间距                       │
│  2xl        48px    页面顶部间距                              │
└─────────────────────────────────────────────────────────────┘
```

## 5. 动画规范

### 5.1 过渡动画

```
┌─────────────────────────────────────────────────────────────┐
│  过渡时长                                                    │
├─────────────────────────────────────────────────────────────┤
│  - fast:    150ms  (按钮状态变化)                             │
│  - normal:  300ms  (页面切换、展开收起)                        │
│  - slow:    500ms  (环形进度、完成动画)                        │
│                                                             │
│  缓动函数                                                    │
│  - ease-in-out: 默认过渡                                      │
│  - spring: 弹性动画 (完成庆祝)                                 │
│  - linear: 进度条填充                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 关键动画

| 场景 | 动画效果 | 时长 |
|------|---------|------|
| 打卡成功 | ✅ 图标放大 + 旋转 | 500ms |
| 完成本组 | 按钮缩放反馈 | 150ms |
| 休息倒计时 | 数字跳动 | 每秒 |
| 进度更新 | 进度条填充 | 300ms |
| 训练完成 | 🎉 图标弹出 + 彩带 | 800ms |
