## 3. 技术实现方案

### 方案 A：嵌入 WebView（推荐）
```typescript
// 使用 WebView 加载小红书/抖音视频页面
import { WebView } from 'react-native-webview';

<WebView
  source={{ uri: 'https://www.xiaohongshu.com/video/xxx' }}
  allowsFullscreenVideo={true}
/>
```

**优点**：
- 无需下载视频
- 无版权问题（嵌入播放）
- 支持全屏

**缺点**：
- 依赖网络
- 加载速度稍慢

---

### 方案 B：视频 URL 直接播放
```typescript
// 使用 react-native-video 播放 MP4
import Video from 'react-native-video';

<Video
  source={{ uri: 'https://cdn.example.com/video.mp4' }}
  controls={true}
  fullscreen={true}
/>
```

**优点**：
- 播放流畅
- 可缓存离线

**缺点**：
- 需要获取视频直链
- 可能有版权问题

---

### 方案 C：自建视频资源
```
1. 拍摄/制作原创视频
2. 上传到 CDN/OSS
3. 使用直链播放
```

**优点**：
- 无版权风险
- 加载速度快
- 可完全控制

**缺点**：
- 需要时间/成本
- MVP 阶段不现实

## 5. 版权注意事项

### ✅ 可以做
- 嵌入公开视频（WebView）
- 使用 CC 协议视频
- 联系创作者授权
- 使用自建原创视频

### ❌ 不能做
- 直接下载未授权视频到服务器
- 去除水印后使用
- 声称视频是自己的
- 商业使用未授权内容

## 6. 视频资源数据结构

```typescript
interface ExerciseVideo {
  id: string;
  exerciseId: string;        // 关联的动作 ID
  title: string;             // 视频标题
  source: 'xiaohongshu' | 'douyin' | 'bilibili' | 'custom';
  embedUrl?: string;         // WebView 嵌入地址
  directUrl?: string;        // MP4 直链（可选）
  thumbnailUrl: string;      // 封面图
  duration: number;          // 时长（秒）
  author: string;            // 作者/博主
  authorized: boolean;       // 是否已授权
  createdAt: Date;
}
```
