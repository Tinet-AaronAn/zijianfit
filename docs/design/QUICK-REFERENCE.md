## 🎨 配色速查

| 用途 | 色值 | 预览 |
|------|------|------|
| 主色（按钮/强调） | `#FF6B35` | 🟠 |
| 深色背景/标题 | `#1A1A2E` | ⚫ |
| 成功/完成 | `#10B981` | 🟢 |
| 标题文字 | `#1F2937` | ⚫ |
| 正文文字 | `#374151` | ⚫ |
| 次要文字 | `#6B7280` | ⚫ |
| 页面背景 | `#F9FAFB` | ⚪ |
| 卡片背景 | `#FFFFFF` | ⚪ |
| 分割线 | `#E5E7EB` | ⚪ |

---

## 📐 间距速查

```
xs  = 4px   图标与文字
sm  = 8px   相关元素
md  = 16px  标准内边距
lg  = 24px  区块间距
xl  = 32px  页面边距
2xl = 48px  页面顶部
```

---

## 📝 字号速查

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 32px | Bold | 页面主标题 |
| H1 | 24px | Bold | 区块标题 |
| H2 | 20px | Semi | 卡片标题 |
| H3 | 18px | Semi | 小标题 |
| Body1 | 16px | Regular | 正文 |
| Body2 | 14px | Regular | 次要内容 |
| Caption | 12px | Regular | 辅助说明 |

---

## ✅ 状态标识

| 状态 | 图标 | 背景色 |
|------|------|--------|
| 已完成 | ✅ | `#D1FAE5` |
| 休息日 | 💤 | `#F3F4F6` |
| 今日 | - | 白色 + 橙色边框 |
| 待完成 | ○ | `#FFFFFF` |

---

## 🎯 关键交互

1. **开始训练** → 训练引导页
2. **完成本组** → 休息倒计时 → 下一组
3. **训练完成** → 完成页 → 返回首页
4. **点击日期** → 训练详情页
