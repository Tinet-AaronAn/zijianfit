## 2. 测试场景详细规划

### 2.1 用户认证场景

#### 场景 1.1：用户注册

**优先级**: P0  
**测试类型**: API + E2E  
**状态**: ✅ 完成

**流程**:
```
1. 打开 App → 点击"注册"
2. 填写用户名、密码、确认密码
3. 点击"注册"按钮
4. 注册成功 → 自动登录 → 进入首页
```

**验证点**:
- [x] 用户名格式验证（4-20字符，字母数字下划线）
- [x] 密码格式验证（6-20字符，至少包含字母和数字）
- [x] 两次密码一致性验证
- [x] 用户名唯一性检查
- [x] 密码 bcrypt 加密
- [x] JWT Token 生成
- [x] 注册成功后自动登录

**API 依赖**:
- `POST /api/auth/register`
