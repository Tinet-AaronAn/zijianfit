## 2. 测试场景详细规划

### 2.1 用户认证场景

#### 场景 1.1：新用户首次使用（微信登录 → 获取手机号 → 进入首页）

**用户故事**: US1  
**优先级**: P0  
**测试类型**: E2E + API

**流程**:
```
1. 打开 App → 显示登录页
2. 点击"微信登录" → 跳转微信授权
3. 微信授权成功 → 返回 App
4. 显示"获取手机号"引导页
5. 点击"授权手机号" → 微信一键获取
6. 手机号绑定成功 → 跳转首页
```

**验证点**:
- [ ] 微信 SDK 调用正确
- [ ] code 换取 openid 成功
- [ ] 用户记录创建成功
- [ ] JWT Token 保存到本地
- [ ] 手机号解密正确
- [ ] 首页数据加载正常

**API 依赖**:
- `POST /api/auth/wechat`
- `POST /api/auth/phone`
- `GET /api/plans/current`

---

#### 场景 1.2：老用户自动登录（Token 有效）

**优先级**: P0  
**测试类型**: E2E + API

**流程**:
```
1. 打开 App → 检查本地 Token
2. Token 有效 → 自动登录
3. 加载用户数据 → 显示首页
```

**验证点**:
- [ ] AsyncStorage 读取 Token
- [ ] Token 验证接口调用
- [ ] 用户信息加载
- [ ] 无感登录体验

**API 依赖**:
- `GET /api/auth/me`

---

#### 场景 1.3：Token 过期处理（自动刷新）

**优先级**: P0  
**测试类型**: API

**流程**:
```
1. API 请求返回 401
2. 自动调用刷新接口
3. 获取新 Token
4. 重试原请求
```

**验证点**:
- [ ] 401 响应识别
- [ ] 刷新接口调用
- [ ] 新 Token 保存
- [ ] 请求重试机制
- [ ] 刷新失败跳转登录页

**API 依赖**:
- `POST /api/auth/refresh`

---

#### 场景 1.4：微信授权失败处理

**测试类型**: E2E

**验证点**:
- [ ] 错误提示友好
- [ ] 重试按钮可用

---

#### 场景 1.5：手机号授权拒绝处理
