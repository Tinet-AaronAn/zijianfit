# ❓ ZijianFit 常见问题 (FAQ)

**最后更新**: 2026-03-09

## 📱 App 使用问题

### 1. 注册与登录

#### Q1.1: 用户名有什么要求？
**A**: 用户名要求：
- 长度：4-20 个字符
- 字符：字母、数字、下划线
- 示例：`test_user123`、`JohnDoe`、`user_2026`
- 不能包含：中文、空格、特殊符号

---

#### Q1.2: 密码有什么要求？
**A**: 密码要求：
- 长度：6-20 个字符
- 必须包含：字母和数字
- 可选包含：特殊符号（@$!%*#?&）
- 示例：`Test123456`、`Pass@word1`、`MyP4ssword`
- 不能：纯数字、纯字母

---

#### Q1.3: 忘记密码怎么办？
**A**: 当前版本暂不支持找回密码，请联系管理员重置：
- 联系方式：安老师
- 重置后请及时修改密码

---

#### Q1.4: 登录失败显示"用户不存在"？
**A**: 可能原因：
1. 用户名输入错误（区分大小写）
2. 账号未注册
3. 账号被删除

解决方法：
- 检查用户名拼写
- 尝试重新注册
- 联系管理员

---

#### Q1.5: Token 过期了怎么办？
**A**: Token 有效期 7 天，过期后：
1. App 会自动提示重新登录
2. 输入用户名密码重新登录
3. 不需要重新注册

---

### 2. 训练计划

#### Q2.1: 训练计划可以修改吗？
**A**: 当前版本暂不支持自定义计划，计划由系统预设。
- 预设计划：45岁健身计划（降血糖+降血脂+稳定增肌）
- 计划周期：7 天循环
- 如需调整：联系管理员

---

#### Q2.2: 如何查看其他周的计划？
**A**: 当前版本只显示本周计划。
- 计划数据：存储在本地数据库
- 历史记录：暂不支持查看
- 未来版本：将支持多周查看

---

#### Q2.3: 训练日历上的图标是什么意思？
**A**: 图标说明：
- ✅ 绿色勾：已完成训练
- 💤 灰色睡：休息日
- ○ 空心圆：待完成训练
- 橙色边框：今天的训练

---

#### Q2.4: 休息日可以训练吗？
**A**: 不建议。休息日的作用：
- 肌肉恢复
- 避免过度训练
- 降低受伤风险
- 保持训练热情

建议：休息日可以做一些轻度活动（散步、拉伸）

---

### 3. 跟练模式

#### Q3.1: 视频加载很慢怎么办？
**A**: 解决方法：
1. 切换到 Wi-Fi 网络
2. 等待视频缓冲完成
3. 重启 App 重试
4. 检查手机存储空间

---

#### Q3.2: 视频播放失败怎么办？
**A**: 可能原因和解决方法：
1. 网络问题 → 检查网络连接
2. 视频资源失效 → 联系管理员更新
3. 视频格式不支持 → 更新 App 版本
4. 内存不足 → 清理手机存储

---

#### Q3.3: 训练记录没有保存怎么办？
**A**: 确保完成以下步骤：
1. 完成训练后点击"完成本轮"按钮
2. 不要中途强制关闭 App
3. 确保网络连接正常
4. 检查后端服务是否运行

---

#### Q3.4: 如何跳过某个动作？
**A**: 跳过步骤：
1. 点击"跳过此动作"按钮
2. 确认弹窗点击"确定"
3. 进入下一个动作

注意：跳过的动作不计入完成统计

---

#### Q3.5: 训练中接电话怎么办？
**A**: 接电话会暂停视频播放，挂断后：
1. 视频会自动恢复播放
2. 训练进度保留
3. 可以继续训练

建议：训练时开启"勿扰模式"

---

#### Q3.6: 训练中途退出会怎样？
**A**: 退出时有两个选项：
1. **保存进度**：下次可继续（预留功能）
2. **放弃进度**：当前训练记录丢失

建议：完成当轮训练后再退出

---

### 4. 训练统计

#### Q4.1: 统计数据是如何计算的？
**A**: 计算方式：
- **完成率**：已完成训练天数 / 总训练天数
- **训练天数**：本周已完成训练的次数
- **总组数**：所有动作的组数总和
- **消耗卡路里**：估算值（仅供参考）

---

#### Q4.2: 为什么统计数据不准确？
**A**: 可能原因：
1. 训练记录未正确保存
2. 网络同步失败
3. 数据缓存问题

解决方法：
1. 下拉刷新统计页面
2. 检查网络连接
3. 重启 App

---

#### Q4.3: 可以查看历史统计吗？
**A**: 当前版本只显示本周统计。
- 历史数据：暂不支持查看
- 数据导出：暂不支持
- 未来版本：将支持多周统计

## 🏋️ 健身训练问题

### 5. 训练计划设计

#### Q5.1: 为什么每周训练 5 天？
**A**: 训练频率设计：
- **力量训练**：3 天（周一、三、六）
- **有氧训练**：2 天（周二、四）
- **间歇训练**：1 天（周日）
- **休息**：1 天

好处：
- 肌肉充分恢复
- 避免过度训练
- 保持训练热情

---

#### Q5.2: 哑铃重量如何选择？
**A**: 本计划建议重量：
- **标准重量**：6.5kg/只
- **初学者**：从 4-5kg 开始
- **进阶者**：可增加到 8-10kg

选择标准：
- 能够完成规定次数
- 最后 2-3 次感到吃力
- 保持正确姿势

---

#### Q5.3: 组间休息多久合适？
**A**: 休息时间建议：
- **力量训练**：45-60 秒
- **有氧训练**：30-45 秒
- **间歇训练**：2 分钟（慢跑）

休息时可以：
- 喝水
- 深呼吸
- 轻度拉伸

---

#### Q5.4: 训练时间如何安排？
**A**: 最佳训练时间：
- **推荐**：餐后 60-90 分钟
- **避免**：餐后立即、睡前 2 小时内
- **个人调整**：根据自己的作息习惯

---

#### Q5.5: 训练强度如何把握？
**A**: 强度判断标准：
- **力量训练**：每组最后 2-3 次感到吃力
- **慢跑**：心率 120-135 bpm，可以正常对话
- **间歇跑**：心率 140-150 bpm，只能说短语

主观感受：
- 😅 轻松：强度太低，增加重量
- 😓 适中：强度合适，保持
- 😫 吃力：强度太高，降低重量

---

### 6. 健身效果

#### Q6.1: 多久能看到效果？
**A**: 预期效果时间线：
- **1-2 周**：适应训练，肌肉酸痛减少
- **3-4 周**：力量提升，动作更熟练
- **5-8 周**：体型变化，体重下降
- **8-12 周**：明显效果，血糖血脂改善

建议：坚持 8 周以上

---

#### Q6.2: 如何记录体重和血糖？
**A**: 当前版本暂不支持记录。
- 建议使用：其他健康 App 记录
- 未来版本：将支持健康数据记录

---

#### Q6.3: 训练后肌肉酸痛怎么办？
**A**: 肌肉酸痛是正常现象，缓解方法：
1. 充分拉伸（5-10 分钟）
2. 热水澡或泡脚
3. 轻度按摩
4. 保证充足睡眠
5. 补充蛋白质

如果持续酸痛超过 3 天，请咨询医生。

## 🔧 技术问题

### 7. App 运行问题

#### Q7.1: App 启动很慢怎么办？
**A**: 可能原因和解决方法：
1. 手机性能不足 → 清理后台应用
2. 网络连接慢 → 切换到 Wi-Fi
3. 数据量大 → 清理缓存
4. App 版本旧 → 更新到最新版

---

#### Q7.2: App 崩溃怎么办？
**A**: 解决方法：
1. 重启 App
2. 重启手机
3. 清理 App 缓存
4. 重新安装 App
5. 联系管理员反馈

---

#### Q7.3: 网络请求失败怎么办？
**A**: 检查清单：
- [ ] 后端服务是否运行
- [ ] API 地址是否正确
- [ ] 手机网络是否正常
- [ ] 是否连接到正确的网络

模拟器网络设置：
- Android 模拟器：使用 `10.0.2.2` 访问宿主机
- iOS 模拟器：使用 `localhost` 访问本机

---

#### Q7.4: 如何更新 App？
**A**: 更新方式：
1. **开发版**：重新运行 `npm run android`
2. **正式版**：GitHub Releases 下载新版本

### 8. 数据问题

#### Q8.1: 数据会丢失吗？
**A**: 数据存储方式：
- **本地存储**：AsyncStorage
- **数据库**：SQLite（后端）
- **云同步**：暂不支持

建议：
- 定期备份数据
- 不要随意清除 App 数据
- 未来版本将支持云同步

---

#### Q8.2: 如何备份数据？
**A**: 当前版本暂不支持备份。
- 建议截图保存重要数据
- 手动记录训练进度
- 未来版本将支持数据导出

---

#### Q8.3: 可以在多个设备使用吗？
**A**: 当前版本不支持多设备同步。
- 每个 App 独立运行
- 数据存储在本地
- 未来版本将支持云端同步

## 🚀 开发者问题

### 9. 开发环境

#### Q9.1: 如何搭建开发环境？
**A**: 环境要求：
- Node.js 18+
- React Native CLI
- Android Studio（Android 开发）
- Xcode（iOS 开发，仅 macOS）

详细步骤：参考 [QUICKSTART.md](../QUICKSTART.md)

---

#### Q9.2: 依赖安装失败怎么办？
**A**: 解决方法：
```bash
# 清理缓存
npm cache clean --force

# 删除 node_modules
rm -rf node_modules package-lock.json

# 重新安装
npm install --legacy-peer-deps
```

---

#### Q9.3: Metro Bundler 启动失败？
**A**: 解决方法：
```bash
# 清理缓存
npm start -- --reset-cache

# 或删除缓存目录
rm -rf $TMPDIR/metro-*
rm -rf $TMPDIR/haste-map-*
```

---

#### Q9.4: Android 构建失败？
**A**: 解决方法：
```bash
# 清理 Android 缓存
cd android
./gradlew clean
cd ..

# 重新构建
npm run android
```

## 💡 使用建议

### 11. 最佳实践

#### Q11.1: 如何坚持训练？
**A**: 坚持训练的技巧：
1. **设定目标**：每周完成 5 天训练
2. **记录进度**：每次训练后记录
3. **寻找伙伴**：和家人朋友一起练
4. **奖励自己**：完成一周后给自己奖励
5. **保持习惯**：固定时间训练

---

#### Q11.2: 训练时注意什么？
**A**: 训练注意事项：
1. **训练前**：
   - 充分热身（5-10 分钟）
   - 检查哑铃重量
   - 准备饮用水

2. **训练中**：
   - 保持正确呼吸
   - 动作缓慢可控
   - 感到不适立即停止

3. **训练后**：
   - 充分拉伸（5-10 分钟）
   - 补充水分和蛋白质
   - 记录训练感受

---

#### Q11.3: 如何调整训练强度？
**A**: 调整方法：
- **增加强度**：
  - 增加哑铃重量
  - 增加每组次数
  - 缩短休息时间

- **降低强度**：
  - 减少哑铃重量
  - 减少每组次数
  - 延长休息时间

---

#### Q11.4: 训练计划可以跳过吗？
**A**: 不建议跳过。如果必须跳过：
- **跳过 1-2 天**：正常，继续即可
- **跳过 3-5 天**：从原计划继续
- **跳过 1 周以上**：建议从头开始
