## 1. 用户认证模块

### 1.1 用户注册

#### 功能描述
新用户通过用户名密码注册账号

#### 用户故事
```
作为一个新用户，
我想要快速注册账号，
以便开始使用健身计划。
```

#### 使用流程
```
打开 App → 点击"立即注册" → 填写表单 → 点击"注册" → 自动登录 → 进入首页
```

#### 输入字段
| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 用户名 | 文本 | 是 | 4-20字符，字母数字下划线 |
| 密码 | 密码 | 是 | 6-20字符，至少包含字母和数字 |
| 确认密码 | 密码 | 是 | 与密码一致 |
| 昵称 | 文本 | 否 | 最多20字符 |

#### 验证规则
```typescript
// 用户名验证
const usernameRegex = /^[a-zA-Z0-9_]{4,20}$/;

// 密码验证（至少包含字母和数字）
const passwordRegex = /^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d@$!%*#?&]{6,20}$/;
```

#### 错误提示
| 错误类型 | 提示信息 |
|---------|---------|
| 用户名已存在 | "用户名已被使用，请换一个" |
| 用户名格式错误 | "用户名格式不正确（4-20字符，字母数字下划线）" |
| 密码格式错误 | "密码长度应为6-20字符，至少包含字母和数字" |
| 密码不一致 | "两次密码输入不一致" |

#### 成功反馈
- ✅ 显示"注册成功"提示
- ✅ 自动保存 Token 到本地
- ✅ 跳转到首页
- ✅ 显示欢迎信息

### 1.2 用户登录

#### 功能描述
已注册用户通过用户名密码登录

#### 使用流程
```
打开 App → 输入用户名密码 → 点击"登录" → 验证成功 → 进入首页
```

#### 输入字段
| 字段 | 类型 | 必填 |
|------|------|------|
| 用户名 | 文本 | 是 |
| 密码 | 密码 | 是 |

#### 认证流程
```
1. 前端验证输入格式
2. 发送 POST /api/auth/login
3. 后端验证用户名密码
4. 生成 JWT Token（7天有效）
5. 返回 Token + 用户信息
6. 前端保存 Token 到 AsyncStorage
7. 跳转首页
```

#### 自动登录
- App 启动时检查本地 Token
- Token 有效 → 自动登录
- Token 过期 → 跳转登录页

#### Token 刷新
- Token 有效期：7 天
- 自动刷新：每次打开 App 时检查
- 手动刷新：调用 `POST /api/auth/refresh`

## 5. 数据存储

### 5.1 本地存储

#### 存储内容
| 数据类型 | 存储位置 | 有效期 |
|---------|---------|--------|
| 用户 Token | AsyncStorage | 7天 |
| 用户信息 | AsyncStorage | 长期 |
| 训练计划 | 内存缓存 | 会话期间 |
| 训练进度 | 内存 | 会话期间 |

#### 存储实现
```typescript
// 使用 Zustand + AsyncStorage
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import AsyncStorage from '@react-native-async-storage/async-storage';

const useAuthStore = create(
  persist(
    (set) => ({
      user: null,
      token: null,
      setUser: (user) => set({ user }),
      setToken: (token) => set({ token }),
    }),
    {
      name: 'auth-storage',
      storage: createJSONStorage(() => AsyncStorage),
    }
  )
);
```

## 7. 性能优化

### 7.2 数据缓存优化

#### 缓存策略
- **计划数据**：缓存 1 小时
- **用户信息**：长期缓存，登录时更新
- **训练进度**：实时更新，本地保存

#### 实现方式

## 8. 安全性

### 8.1 Token 安全

#### 安全措施
- Token 存储在 AsyncStorage（加密存储）
- Token 有效期 7 天
- Token 自动刷新机制
- 退出登录时清除 Token

#### 实现方式
```typescript
// Token 刷新拦截器
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // Token 过期，尝试刷新
      const newToken = await refreshToken();
      // 重试原请求
      return api.request(error.config);
    }
    return Promise.reject(error);
  }
);
```
