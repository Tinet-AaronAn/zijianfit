## 1. 项目概述

### 1.1 产品定位
面向家庭健身用户（尤其哑铃训练）的健身计划管理工具，帮助用户坚持每周训练。

### 1.2 核心价值
- **降低坚持门槛**: 通过计划提醒 + 进度跟踪
- **专业动作指导**: 哑铃训练视频示范
- **数据驱动改进**: 每周统计 + 个性化建议

### 1.3 目标用户
- 有哑铃的家庭健身用户
- 健身新手，需要动作指导
- 希望系统化训练的人群

## 3. 功能清单（优先级排序）

### 🔴 P0 - 核心功能（必须完成）

#### F1. 用户注册
- **描述**: 用户通过用户名密码注册
- **输入**: 用户名、密码、确认密码、昵称（可选）
- **输出**: 用户身份 + token
- **API**: `POST /api/auth/register`
- **验证规则**:
  - 用户名: 4-20字符，字母数字下划线
  - 密码: 6-20字符，至少包含字母和数字
- **优先级**: P0
- **状态**: ✅ 已完成

#### F2. 用户登录
- **描述**: 用户名密码登录
- **输入**: 用户名、密码
- **输出**: 用户信息 + JWT Token（7天有效）
- **API**: `POST /api/auth/login`
- **优先级**: P0
- **状态**: ✅ 已完成

#### F3. 周计划展示
- **描述**: 展示本周 7 天训练计划
- **输入**: 用户 ID + 周次
- **输出**: 7 天计划列表（每日：休息/训练 + 动作列表）
- **API**: `GET /api/plans/current`
- **优先级**: P0
- **状态**: ✅ 已完成

#### F4. 训练详情页
- **描述**: 单日训练动作详情
- **输入**: 计划 ID + 日期
- **输出**: 动作列表（名称、组数、次数、休息时间、视频链接）
- **API**: `GET /api/plans/{planId}/days/{day}`
- **优先级**: P0
- **状态**: ✅ 已完成

#### F5. 视频播放
- **描述**: 动作示范视频播放
- **输入**: 视频 URL
- **输出**: 全屏播放器
- **技术**: React Native Video
- **优先级**: P0
- **状态**: ✅ 已完成

#### F6. 跟练模式
- **描述**: 进入训练模式，视频 + 轮次计数
- **流程**:
  1. 点击"跟练模式"按钮
  2. 播放训练视频
  3. 显示当前轮次/总轮次
  4. 用户完成一轮，点击"完成本轮"
  5. 自动进入下一轮
  6. 全部完成后显示庆祝页面
- **输入**: 计划 ID + 日期
- **输出**: 训练完成状态
- **优先级**: P0
- **状态**: ✅ 已完成

## 4. 用户故事

### US1. 新用户首次使用
```
作为一个新用户，
我想要通过用户名密码快速注册并登录，
以便开始使用健身计划。
```
**验收标准**:
- 填写用户名、密码、确认密码
- 可选填写昵称
- 注册成功后自动登录
- 进入首页

---

### US2. 查看训练计划
```
作为一个已登录用户，
我想要看到本周的训练计划，
以便知道每天该练什么。
```
**验收标准**:
- 首页展示 7 天计划卡片
- 训练日显示"上肢力量"等标签
- 休息日显示"休息"标签
- 点击某天进入详情

---

### US3. 跟练训练
```
作为一个训练中的用户，
我想要按照跟练模式完成训练，
以便通过视频指导系统化完成动作。
```
**验收标准**:
- 点击"跟练模式"按钮进入训练模式
- 显示训练视频（循环播放）
- 显示当前轮次/总轮次
- 完成一轮后点击"完成本轮"
- 全部完成后显示庆祝页面

---

### US4. 观看动作示范
```
作为一个训练中的用户，
我想要观看动作示范视频，
以便确保动作标准。
```
**验收标准**:
- 跟练模式自动播放训练视频
- 视频全屏播放，支持暂停/播放
- 可重复播放

---

### US5. 查看统计
```
作为一个坚持训练的用户，
我想要看到本周的统计数据，
以便了解我的训练情况。
```
**验收标准**:
- 统计页显示：完成率、训练天数
- 显示个性化建议文字
- 显示打卡日历

---

### US6. 接收提醒
```
作为一个容易忘记训练的用户，
我想要收到每日训练提醒，
以便按时训练。
```
**验收标准**:
- 设置页面可设置提醒时间
- 每天固定时间收到推送
- 点击推送进入训练页面

## 6. 数据模型（简版）

### User
```typescript
{
  id: string;
  username: string;      // 用户名（唯一）
  password: string;      // 密码（bcrypt 加密）
  openid?: string;       // 微信 openid（可选，预留）
  phone?: string;        // 手机号（可选）
  nickname?: string;     // 昵称
  avatar?: string;       // 头像 URL
  createdAt: Date;
  updatedAt: Date;
}
```

### Plan
```typescript
{
  id: string;
  userId?: string;       // 用户 ID（可选，公共计划为 null）
  name: string;          // 计划名称
  description: string;   // 计划描述
  targetAudience: string;// 目标人群
  weekNumber: number;    // 周数
  year: number;          // 年份
  isActive: boolean;     // 是否激活
  createdAt: Date;
  updatedAt: Date;
}
```

### DayPlan
```typescript
{
  id: string;
  planId: string;
  dayOfWeek: number;     // 1-7 (周一到周日)
  dayName: string;       // 周一、周二等
  isRestDay: boolean;    // 是否休息日
  title: string;         // 训练标题
  description: string;   // 描述
  totalDuration: number; // 总时长(分钟)
}
```

### Exercise
```typescript
{
  id: string;
  dayPlanId: string;
  name: string;          // 动作名称
  type: string;          // strength, cardio, hiit, circuit
  sets: number;          // 组数
  reps: number;          // 每组次数
  duration: number;      // 持续时间(秒)
  restSeconds: number;   // 休息时间(秒)
  videoUrl: string;      // 视频链接
  videoSource: string;   // 视频来源
  muscleGroup: string;   // 肌群
  order: number;         // 排序
}
```

### Progress
```typescript
{
  id: string;
  userId: string;
  planId: string;
  date: Date;            // 训练日期
  completedExercises?: string;  // JSON: ["exercise-id-1"]
  completedSets?: string;       // JSON: {"exercise-id-1": 3}
  isCompleted: boolean;  // 是否完成当日训练
  createdAt: Date;
  updatedAt: Date;
}
```

## 7. 技术方案（简述）

### 前端（React Native）
- **导航**: React Navigation 6
- **状态管理**: Zustand
- **网络请求**: Axios
- **视频播放**: react-native-video
- **存储**: @react-native-async-storage/async-storage

### 后端（Koa）
- **框架**: Koa 2
- **数据库**: SQLite + Prisma ORM
- **认证**: JWT
- **密码加密**: bcrypt
- **安全**: Helmet + CORS + Rate Limit
