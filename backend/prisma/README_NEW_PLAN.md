# 45岁健身计划 - 数据导入指南

## 📋 文件说明

### 1. `seed-new-plan.ts` - 导入训练计划
- 创建新的训练计划
- 导入7天的训练安排
- 创建所有训练动作
- **注意**：视频链接暂时为空

### 2. `update-video-urls.ts` - 更新视频链接
- 批量更新动作的视频链接
- 基于用户选择的视频填充 BV 号

---

## 🚀 使用步骤

### 步骤1：导入训练计划

```bash
cd backend
npx ts-node prisma/seed-new-plan.ts
```

**预期输出**：
```

📋 创建训练计划...
✅ 计划创建成功: xxx-xxx-xxx

📅 创建每日训练...
  ✅ 周一 - 上肢力量 (5个动作)
  ✅ 周二 - 上肢力量 + 慢跑 (8个动作)
  ✅ 周三 - 下肢力量 (4个动作)
  ✅ 周四 - 慢跑 (3个动作)
  ✅ 周五 - 上肢力量 + 慢跑 (8个动作)

  ✅ 周日 - 间歇有氧 + 腹部训练 (4个动作)

🎉 训练计划导入完成！
```

---

### 步骤2：选择视频

1. 查看 `../../VIDEO_RECOMMENDATIONS.md`
2. 为每个动作选择1个视频
3. 记录 BV 号（Bilibili视频ID）

---

### 步骤3：更新视频链接

编辑 `update-video-urls.ts`，填充 `videoMapping`：

```typescript
const videoMapping: Record<string, { url: string; author: string; bvId?: string }> = {
  '哑铃对握卧推': {
    url: 'https://www.bilibili.com/video/',
    author: '跟练健身Online',
    bvId: 'BV1abc123', // 填入实际BV号
  },
  // ... 其他动作
};
```

然后运行：

```bash
npx ts-node prisma/update-video-urls.ts
```

**预期输出**：
```
🎬 开始更新视频链接...

✅ 哑铃对握卧推 - 已更新 (1个)
✅ 哑铃俯身划船 - 已更新 (1个)
...

📊 更新统计：
  - 成功更新：10个动作
  - 未更新：0个动作
```

## 📊 训练计划统计

### 每周训练安排

| 星期 | 训练内容 | 时长 |
|------|----------|------|
| 周一 | 上肢力量 | 20分钟 |
| 周二 | 上肢力量 + 慢跑 | 50分钟 |
| 周三 | 下肢力量 | 20分钟 |
| 周四 | 慢跑 | 30分钟 |
| 周五 | 上肢力量 + 慢跑 | 50分钟 |
| 周六 | 下肢力量 | 20分钟 |
| 周日 | 间歇有氧 + 腹部 | 40分钟 |

**每周总时长**：约 180 分钟

---

### 动作统计

**上肢力量**（5个动作）：
1. 哑铃对握卧推 - 3组×15次
2. 哑铃俯身划船 - 3组×15次
3. 哑铃站姿推举 - 3组×15次
4. 哑铃站姿弯举 - 3组×15次
5. 哑铃夹胸 - 3组×15次

**下肢力量**（4个动作）：
1. 哑铃深蹲 - 3组×15次
2. 哑铃硬拉 - 3组×15次
3. 哑铃左弓步 - 3组×15次
4. 哑铃右弓步 - 3组×15次

**腹部训练**（1个动作）：
1. 腹部踢腿 - 3组×20次

**慢跑训练**（3个阶段）：
1. 热身 - 5分钟（6 km/h）
2. 稳态跑 - 20分钟（7.5-8 km/h）
3. 降速 - 5分钟（5 km/h）

**间歇有氧**（3个阶段）：
1. 热身 - 5分钟
2. 间歇训练 - 18分钟（6组：快跑1分钟+慢跑2分钟）
3. 冷身 - 7分钟

---

## ⚠️ 注意事项

1. **哑铃重量**：6.5kg/只
2. **力量训练**：3组×15次（腹部3组×20次）
3. **组间休息**：45-60秒
4. **有氧心率**：慢跑 120-135 bpm，间歇跑 140-150 bpm
5. **最佳训练时间**：餐后 60-90 分钟

## 🔧 故障排除

### 问题1：找不到动作
**原因**：数据库名称不匹配
**解决**：检查 `update-video-urls.ts` 中的动作名称是否与数据库一致

### 问题2：Prisma 连接失败
**原因**：数据库未启动
**解决**：运行 `npx prisma generate` 和 `npx prisma migrate dev`

### 问题3：视频链接无效
**原因**：BV 号错误或视频已删除
**解决**：在 Bilibili 搜索关键词，重新获取 BV 号
