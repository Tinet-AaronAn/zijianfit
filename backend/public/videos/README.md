# 视频资源说明

## 📁 视频文件位置

```
zijianfit/backend/public/videos/
├── upper-body.mp4    # 上肢力量训练（6分钟+）
└── lower-body.mp4    # 下肢力量训练（6分钟+）
```

## 🎬 视频内容要求

### upper-body.mp4（上肢力量训练）
- **时长**: 6-7 分钟
- **内容**: 包含 8 个上肢力量训练动作的引领
  - 哑铃推举
  - 高位下拉
  - 器械推胸
  - 哑铃弯举
  - 绳索下压
  - 哑铃划船
  - 等等...
- **风格**: 
  - 专业教练示范
  - 有倒计时提示
  - 动作名称字幕
  - 流畅连贯

### lower-body.mp4（下肢力量训练）
- **时长**: 6-7 分钟
- **内容**: 包含 8 个下肢力量训练动作的引领
  - 器械腿举
  - 罗马尼亚硬拉
  - 坐姿腿屈伸
  - 站姿提踵
  - 深蹲
  - 弓步
  - 等等...
- **风格**: 
  - 专业教练示范
  - 有倒计时提示
  - 动作名称字幕
  - 流畅连贯

## 📐 访问地址

视频上传后，可以通过以下地址访问：

- **模拟器**: `http://10.0.2.2:3001/videos/upper-body.mp4`
- **真机测试**: `http://<电脑IP>:3001/videos/upper-body.mp4`

## 🔄 训练流程

### 力量训练（周一/周三/周日）
1. 用户点击"跟练模式"
2. 自动播放视频（6分钟）
3. 用户跟着视频做动作
4. 视频播完，用户点击"完成这一轮"
5. 重复 3-4 轮
6. 全部完成，显示庆祝页面

### 有氧训练（周五）
1. 用户点击"跟练模式"
2. 显示跑步提示（无需视频）
3. 用户跑步
4. 跑完回来点击"完成跑步"
5. 显示庆祝页面

## ⚠️ 注意事项

1. **视频格式**: MP4 格式，建议 H.264 编码
2. **文件大小**: 建议不超过 50MB
3. **分辨率**: 建议 720p 或 1080p
4. **命名**: 必须严格按照 `upper-body.mp4` 和 `lower-body.mp4` 命名
5. **上传位置**: 必须放在 `backend/public/videos/` 目录
